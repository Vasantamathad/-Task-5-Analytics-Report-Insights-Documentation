# Retail Sales Analysis Using Microsoft Excel

## Project Overview
This project summarizes retail sales figures using Microsoft Excel. It focuses on comparing revenue by product and by region, and presenting the results through charts and a dashboard.

The workbook was prepared using the summary values visible in the provided screenshots. It is intended as a demonstration of basic sales analysis and visualization.

## Objectives
- Analyze revenue generated by different products.
- Compare revenue across regions.
- Identify the product with the highest revenue.
- Identify the region with the highest revenue.
- Present the results using charts and dashboard elements.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts (as shown in the source screenshots)
- Data visualization

## Key Findings
Based on the figures visible in the screenshots:
- Total revenue: 450,500
- Laptop revenue: 160,000
- Phone revenue: 135,000
- South region revenue: 144,000

## Conclusion
The dashboard helps compare product and regional revenue at a glance. It demonstrates how spreadsheet summaries and charts can support basic business reporting.

## Data Note
The original transaction-level dataset was not included in this package. The findings above are based on the summary figures visible in the screenshots. Add your original CSV file if you have it; do not treat the summary table as the complete transaction dataset.
